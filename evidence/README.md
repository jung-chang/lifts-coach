# Evidence corpus

These are original, conservative summaries of verified primary publication records and official professional guidance. They are maintained manually. The reviewed scope is recorded in each summary: most are abstract-level reviews, not independent full-text risk-of-bias assessments. Confidence labels are editorial judgments, not formal GRADE ratings. Do not interpret population averages as individual guarantees or use these records as injury rehabilitation guidance.

`records.ts` is the bundled runtime index. Keep it and the matching Markdown record consistent when curating updates. Review source changes, newer syntheses and applicability before revising a claim. Topic retrieval supplies relevant records; it does not rank the scientific certainty of an arbitrary generated answer.

Each record includes an identifier, topic tags, original claim, population, confidence, limitations, source and year. No copied papers, figures or copyrighted abstracts are bundled. Training choices still require user review.
