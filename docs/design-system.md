# Lifts Coach visual direction

The owner requested a cleaner, more minimal and aesthetic redesign inspired by the [shadcn Maia preset](https://ui.shadcn.com/create?preset=b6sUiTsN1). This subsequent instruction overrides the original specification's Electric Minimal visual palette and typography. `fitness_app_product_spec.md` remains protected and unchanged; its behavior and data invariants still apply.

The reference preset uses Maia, Olive base, Yellow theme, Olive charts, Geist for headings/body, Lucide icons, default radius, and restrained inverted/translucent selected menus.

## Foundation

- Warm olive canvas `#F5F5F2`, white surfaces, ink `#292D23`, muted olive text `#73796A`, and subtle olive dividers `#E3E6DC`.
- Yellow `#F1D653` is a restrained primary action accent with ink text. Informational charts use muted olive rather than the primary yellow.
- Real self-hosted Geist via `@fontsource-variable/geist`, with 400 body, 500 headings and 600 emphasis. No external font requests or synthetic font labels.
- Roughly 24px card corners, 12–14px fields, pill-shaped prominent actions, and 4px spacing increments. Shadows are limited to layered dialogs/navigation where needed; content surfaces use borders.
- Controls remain at least 44×44px; main actions 48–52px. Tabular numbers support logging. Focus rings are visible and neutral/olive.

## Layout

Train has a single next-session card containing its routine title and plain metadata, followed by simple saved-routine/history lists. Avoid duplicate headings, duplicate Settings actions, generic icon boxes and decorative statistics. Desktop uses intentional columns for the next session and routine list; mobile stacks them.

The owner's newest workout instruction replaces the focused-set interface with an always-visible table for the current exercise: Set, Load, Reps and Done. Editable values and a one-tap checkbox keep logging in the row. There are no set-status dropdowns, table show/hide controls, Next working set overview or Complete Set button. Finish workout is clearly labeled at the top only. This explicitly overrides the protected specification's original focused-set presentation without modifying that specification.

The four columns fit 320px without horizontal panning, with readable decimal loads and 44px interaction areas. Completion keeps its restrained green cue; logging and rest remain deterministic. Exercise navigation stays available. A quiet Options button opens a drawer with working-set, warm-up and replacement actions, optional load modes and a separate workout-sharing section. Live exercise options have no Skip or Move actions and no accordion. Replacement opens a searchable library in the same drawer, matching name, muscle and equipment with visible metadata and an empty state. Changes apply only to today's snapshot; completed sets remain with their original exercise. Mobile navigation has three tabs; desktop navigation remains integrated with the shell. Preserve the mini-player only while an active workout is viewed elsewhere.

The owner's latest Progress refinement puts the workout calendar and weekly volume at the top level. Volume shows completed working sets in Monday–Sunday weeks, excluding warm-ups and skipped or incomplete sets. Exercise stats (including progression suggestions) and full workout history open through secondary clickable rows, with a clear return to Progress. History retains corrections and repeat workouts. Coach looks like a focused conversation, with quiet contextual actions and inspectable approvals. Routine editing and proposals share the same visual controls.

## Semantics and boundaries

Personal exercise instructions are editable under each exercise in the routine editor, persist across routines, and display above the active set table. They remain separate from the session-feedback notes described below. Keep the ordinary Sets / Reps / Target weight row and compact editable workout table. Free-text instructions can describe special sets, percentages, pauses and partial reps without structured percentage controls. Historical instructions come from the workout snapshot. Personal instructions stay private.

Exercise feedback is collapsed under "Notes (optional)" and contains a text note and compact Easy/Good/Hard choices under "How did this exercise feel?" Prior exercise notes use a separate accordion below the exercise card, collapsed by default. Overall workout notes and ratings appear only after Finish workout. Ratings use quiet text buttons with 44px touch targets instead of a wide pill track. Notes stay private, save per session, and are excluded from automatic Coach context and shared responses. Previously saved reps-in-reserve entries remain readable without converting them into qualitative ratings. Repeat starts fresh feedback and uses the same primary button style as Start workout and Finish workout.

Coach is available to every active admitted account through provisioned server-side providers. It has one entry icon in the top-right header on each screen, opening the full Coach view with active-workout context when available. Routine editing uses the same single icon in its dedicated header and retains the unsaved draft while Coach is open; Train or browser Back resumes the draft. Remove duplicate sidebar, workout-title and Progress Coach actions. Proposal origin labels can still identify actual model-generated content.

Exercise Options is removed entirely. The exercise-name picker uses a switch/replace icon and opens replacement search directly; Previous/Next navigates the existing workout. A plus button below the logged rows adds a working set for today only. Added-weight/assistance selection stays inline with the relevant set load, and sharing is chosen after Finish. The elapsed workout timer counts up in minutes and seconds from the saved start timestamp. Search drawers constrain their body to the viewport, keep the focused search field fully visible, and scroll only the result list.

Green `#347A55` confirms completed sets; muted red `#B64E45` identifies destructive/reject actions. AI uses a restrained violet icon/label `#685781`, not purple surfaces. Pending Coach proposals identify their origin explicitly. Deterministic progression uses olive/yellow neutrals and never AI branding. Do not recolor every region or muscle group.

The redesign changes presentation only. Preserve local-first transactions, snapshot/history boundaries, explicit Coach approval, numerical units, durable queues, backups and authenticated Worker configuration. Never add fake user metrics, history or provider responses for visual polish.

## Personal records and quiet completion

Finished workout history and Community share one expanded summary with Set, Load and Reps columns; completed rows have no Type or Done column. Show finish date/time, recorded timezone, total duration, exercise count and working-set count. Checking or unchecking Done during training saves quietly without a toast; Undo remains an inline secondary action.

Personal load records use completed working sets with at least one rep in finished workouts, scoped to one account, stable exercise identity and actual set load mode across the full history. Weighted repetition lifts compare maximum load (per dumbbell where applicable); machine-assisted lifts compare minimum numeric assistance. Pure bodyweight, bands, holds, carries and unmeasured support earn no load record. Added-weight bodyweight repetition lifts form their own record stream. Unknown exercise definitions stay ineligible; custom exercises follow the same conservative measurement policy.

The first eligible performance establishes a baseline. Strict improvements earn one star on the winning set per exercise/load mode/workout; ties and additional reps alone do not. Earlier achievement stars remain after being surpassed. A compact list appears only after Finish when records were achieved; history and Community details mark the winning loads directly without repeating that list. History and feed titles carry one small star when a workout contains an achievement. Exercise stats adds just one best-load or least-assistance line for the selected lift, including its date; no separate record catalog or rankings.

Records are derived by a shared deterministic evaluator rather than saved as permanent badges. Corrections, deletions, imports and synchronized history recalculate them without changing logged sets. Server badges use the author's full history, never the viewer's history or just a loaded feed page. Shared responses contain only achievement set IDs for that shared workout and a feed indicator; they exclude private prior values and workout references. Aggregate best values respect profile-stats sharing. Record computation remains local-first and requires no AI or schema migration.

The owner selected Option A (Simple) for workout previews: routine name, local completion date/time below it, then exercise count and duration on a separate line. Use its generous spacing at phone and desktop sizes; the Compact and Split variants remain examples only. This feed refinement uses one bordered white card component for workout previews in both personal history and Community, and one shared card shell for expanded workout details. Preview fields are the workout's saved routine name, completion date and device-local time (including timezone), performed exercise count and duration. Omit working-set totals, exercise-name previews and relative-only timestamps from these cards. Community adds the author's profile link; owner actions remain available in personal history. The display timezone does not change captured training dates used by history filters. Finished workouts automatically follow the profile's sharing preference after synchronization, with explicit per-workout choices taking priority. The pending summary reflects that preference without requiring a Share click, and older workouts keep their existing visibility.

Workout history uses one full-width date-range trigger. Its shadcn Calendar/Input composition opens in the shared responsive Sheet, with stacked From/To fields on phones, a single-month range calendar and explicit Apply/Cancel. Keep open-ended ranges and captured training-day filtering. Today has a small label and outline on Progress, independent of selected/workout states, and is underlined in the date picker.

The approved notes study now places previous routine feedback above accessible exercise tabs. Each exercise card contains its captured instructions, a pencil-only inline editor, the compact set table and collapsed optional feedback. Previous exercise feedback lives in a separate collapsed accordion below the card. Previous context is labeled “Last workout” and dated from actual history rather than assuming a weekly schedule. Saving instructions updates personal exercise settings and the matching active snapshots through the existing durable transaction; prior workouts remain unchanged.

Active workout set rows support a left swipe to reveal a delete action for that row, with Undo after deletion. Keyboard users can focus a row to reveal the action or press Delete on the row; editing a load or reps field never deletes a row. Vertical scrolling remains available. This set-row gesture replaces the temporary minus control and does not change the explicit removal controls for routine exercises.

Set rows follow the finger during a horizontal swipe and settle open to an 80px trailing red Delete action. Done remains in the sliding row. Short drags settle closed; swiping right, tapping elsewhere or returning to an input closes the action. Only one row opens at a time. Deletion requires tapping Delete, even after a long swipe, and retains the existing Undo. Done accepts deliberate horizontal drags without toggling completion; ordinary taps still toggle immediately. Editable text fields own their gestures, vertical movement cancels a pending swipe, and reduced-motion preferences disable the settling animation.

During training, captured exercise instructions are read-only and appear only when nonblank. Empty instruction headings, placeholder copy and editing controls are hidden. Instructions are edited through the exercise/routine editor, overriding the earlier in-workout pencil editor.

Keep its explanation concise: the community sees workouts, all-history stats and lift records; notes and chats stay private. Remove the separate account-settings checkbox and completion sharing card. Individual privacy choices survive later default changes and synchronization, and still contribute to shared all-history stats.
